01

Check your graphics card

~1 min

You need an NVIDIA card and 32 GB of system RAM is strongly recommended: video models park whatever doesn't fit in VRAM in your RAM. Find out how much VRAM you have:

Press Ctrl + Shift + Esc → Performance → GPU. Read Dedicated GPU memory.

nvidia-smi --query-gpu=name,memory.total --format=csv

Pick your card below. The rest of the page will show the right downloads for it.

12 GBKeep clips short and the resolution low (around 0.5 megapixels, see step 05). One RTX 3060 12 GB owner reports a 10 s clip at ~0.5 MP in about 180 seconds, with 96 GB of system RAM. Got 16 GB on an RTX 30/40? Swap Q3_K_M for Q4_K_M (15.1 GB) for sharper detail.
8 GBLTX-2.5 on 8 GB is experimental and crash-prone, so this tier uses the older LTX-2.3. It still makes video with sound. This guide covers text-to-video on 8 GB. Expect it to be slow: small resolution, short clips, and patience.
02

Install ComfyUI + the GGUF node

~5 min

We'll use the official portable build. It has Python built in, so there's nothing else to install, and the folders are always in the same place.

  1. Download it: ComfyUI_windows_portable_nvidia.7z 2.0 GB
  2. Right-click the file → Extract All into C:\. On Windows 10, use 7-Zip.
    You now have C:\ComfyUI_windows_portable\.
  3. Double-click run_nvidia_gpu.bat in that folder. A black window opens and ComfyUI opens in your browser.
NOTEAlready have ComfyUI? Run update\update_comfyui.bat first. LTX-2.5 needs a recent version. Won't start? Update your NVIDIA driver from the NVIDIA App.

You need git, Python 3.12 or 3.13, and a working NVIDIA driver (nvidia-smi runs).

git clone https://github.com/Comfy-Org/ComfyUI ~/ComfyUI
cd ~/ComfyUI
python -m venv venv
source venv/bin/activate
pip install torch torchvision torchaudio --extra-index-url https://download.pytorch.org/whl/cu130
pip install -r requirements.txt
pip install -U huggingface_hub

Start it, then open 127.0.0.1:8188:

cd ~/ComfyUI && source venv/bin/activate && python main.py
FISHUsing fish shell? Use source venv/bin/activate.fish and replace && with ; and.
NOTEAlready have ComfyUI? Update it first with cd ~/ComfyUI && git pull && pip install -r requirements.txt. LTX-2.5 needs a recent version.

ComfyUI can't read .gguf files on its own. Install the ComfyUI-GGUF node and KJNodes, which the LTX-2.3 workflow uses:

  2. In C:\ComfyUI_windows_portable\, click the address bar, type powershell and press Enter. Then run:

04

Load the workflow

~3 min
  1. Restart ComfyUI once so the new nodes load: close the black window, then run run_nvidia_gpu.bat again.Ctrl + C in the terminal, then start it again.
  2. Click on the ComfyUI page and press R so it sees the new files.
  3. Open Workflow → Browse Templates and search LTX-2.5. Pick the text-to-video or the image-to-video one. Close the missing-models popup.
  4. The loaders sit inside the big grouped node (a subgraph). Open it to see them.
  5. In Load Diffusion Model, pick ltx-2.5-22b-distilled-transformer-nvfp4.safetensors. Go back out of the subgraph.
  6. Double-click empty space, search Unet Loader (GGUF) and add it. Pick LTX-2.5-Distilled-Q3_K_M.gguf, drag its MODEL output to where Load Diffusion Model was connected, then delete the old loader. Go back out of the subgraph.
  7. Download unsloth_flowers.mp4 and drag it onto the ComfyUI page. The workflow is stored inside the video, and it loads.
  8. In the Unet Loader (GGUF) pick ltx-2.3-22b-dev-Q4_K_S.gguf, and in the upscaler loader pick ltx-2.3-spatial-upscaler-x2-1.1.safetensors. Check every other loader shows a file and no red box.
  9. Image to video: click choose file on the Load Image node and pick your picture. No images yet? Make some for free with Z-Image Turbo.
  10. Type your prompt and press Run.
  11. This workflow is text-to-video only. Want image-to-video? It needs LTX-2.5, so a 12 GB card or bigger.
DONEYour video, with sound, appears in the Save Video node and is saved in ComfyUI\output\~/ComfyUI/output/. The first run is slow while the models load.
TIPDescribe the sound too: "rain on a tin roof", "a woman says: we made it". The model makes the audio from your prompt.

If something goes wrong

ERRRed box on a node / "value not in list"
FIXA file is in the wrong folder, or ComfyUI hasn't refreshed. Check step 03, then press R on the ComfyUI page.
ERRCUDA out of memory / crash at the end of a run
FIXLower the width, height or duration (step 05). Running out at the very end means the VAE decode ran out, so lower the size. Close games, browsers with many tabs and other GPU apps.
ERRThe video has no sound
FIXThe audio VAE is missing or not selected. Check the audio VAE file in step 03.
ERR401 / "access to model is restricted"
FIXAccept the licence on the LTX-2.5 page while logged in, then run hf auth login again.
ERRMissing node type / template not found
FIXComfyUI is too old. Run update\update_comfyui.bat in the portable folder. Run git pull in ~/ComfyUI. GGUF tiers: check the GGUF node from step 02 is installed.
ERRVery slow, and system RAM is full
FIXThe model is spilling out of VRAM and RAM. Close other apps, use a smaller size, or pick the next tier down.
